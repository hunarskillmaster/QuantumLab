QuantumLab

An interactive multi-domain computational physics and engineering laboratory featuring 20 real-time simulations.

Try https://quantumlab-interactive-physics-sandbox-760296262693.asia-southeast1.run.app/

20 real-time physics simulation modules spanning mechanics, waves, electromagnetism, thermodynamics, and quantum physicsLive mathematical telemetry and MathJax LaTeX equation renderingInteractive parameter controls, speed scaling, and frame steppingReal-time oscilloscope data visualization and CSV experiment data export.
